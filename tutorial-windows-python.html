Python 入門教學

在 Windows 上安裝 Python、VSCode，寫第一支程式並打包成 .exe。

預計 30 分鐘 · 不需任何程式背景

01安裝 Python

到官網下載 Windows 安裝檔：python.org/downloads，按黃色按鈕下載並執行。

⚠ 最重要的一步 安裝視窗最下方有一個勾選框 Add python.exe to PATH，請務必勾選後再按 Install。沒勾就要重裝。

裝完後驗證。按 Win + R，輸入 cmd，貼入：

cmd
python --version

顯示 Python 3.12.x 即成功。

02安裝 VSCode

下載並安裝（一路 Next）：code.visualstudio.com

打開後加裝兩個擴充套件：

  1. 左側欄點積木圖示（Extensions）。
  2. 搜尋 Python（作者 Microsoft），按 Install。
  3. 搜尋 Chinese (Traditional)，安裝後重啟，介面變繁中。

03寫第一支程式

  1. 桌面建一個資料夾，例如 my_python。
  2. VSCode → File → Open Folder → 選該資料夾。
  3. 新增檔案 hello.py，貼入以下程式碼。
hello.py
from sympy import symbols, diff, integrate, sin, pi

x = symbols('x')
f = sin(x) * x**2

print('f(x)  =', f)
print('f\'(x) =', diff(f, x))
print('∫f dx =', integrate(f, x))
print('f(π)  ≈', f.subs(x, pi).evalf())

input('\nPress Enter to exit...')

先安裝 SymPy。在 VSCode 點 Terminal → New Terminal，貼入：

terminal
pip install sympy

然後按右上角的 ▶ 執行。

04打包成 .exe

在 Terminal 安裝 PyInstaller：

terminal
pip install pyinstaller

打包：

terminal
pyinstaller --onefile hello.py

完成後打開 dist 資料夾，hello.exe 雙擊即可執行，可寄給沒裝 Python 的人。

05疑難排解

pyinstaller 顯示「不是內部或外部命令」

改用 python -m PyInstaller --onefile hello.py。

防毒把 exe 當病毒

常見誤判。加白名單，或改用 --onedir 取代 --onefile。

exe 為什麼那麼大（30 MB+）

正常的，Python 直譯器一起被打包進去了。

雙擊 exe 視窗一閃就消失

程式末尾加 input('Press Enter...') 視窗就會停下來。
